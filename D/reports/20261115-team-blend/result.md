# 결과: blend6에 팀원 모델 추가 (D039) — 실패

검토: reviewer 1회. 해석을 사실 수준으로 낮춤.

기준선 blend6 0.05744, 성공 기준 > 0.05794. RRF c=60.

| 추가 모델 | w 0.3 | w 0.5 | w 1 |
|---|---|---|---|
| BM25 (D036) | 0.05695 | 0.05666 | 0.05556 |
| LightGCN (D037) | 0.05679 | 0.05662 | 0.05520 |
| SimpleX (D038) | 0.05733 | 0.05724 | 0.05706 |
| BM25 .5 + LightGCN .3 + SimpleX .3 | 0.05633 | | |

- 모두 기준선 이하, 기준 미달. BM25·LightGCN은 가중치를 키울수록 떨어진다. SimpleX w0.3은 −16 hits로 SimpleX seed 간 차이(40 hits) 수준이라 "차이 없음"에 가깝다.
- 이유는 확인하지 않았다 (단독 점수가 blend6 구성 모델보다 낮다는 것만 사실). 이전 C LightGCN 블렌드(D035)와 같은 결과.
- 그래서 팀원 모델은 블렌드가 아니라 reranker 후보·피처로만 시험한다 (D040).
