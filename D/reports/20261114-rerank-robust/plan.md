# 계획: 분포 차이에 강한 reranker 피처

- 질문: inner(유저당 약 10건) → final(약 17건)로 커지는 개수형 피처를 비율·순위로 바꾸면, val 점수를 잃지 않으면서 final에서의 분포 차이를 줄일 수 있는가?
- 방법: user_n → 유저 활동량의 fit 내 백분위, user_span → 그대로 두되 일(day) 단위 대신 fit 전체 기간 대비 비율, pop_share는 이미 비율이라 유지, timepop은 유저별 정규화 유지. 나머지 동일 (seed 0).
- 비교 대상 / 베이스라인: rerank_v4 0.06082
- 지표: Recall@20, 키트 score.
- 성공 기준 (결과 보기 전 고정): val ≥ 0.06032 (−0.0005 이내, 비열등)이면 채택. 효과는 LB에서만 드러나므로 val 향상은 요구하지 않는다.
- 한계: val 평가도 inner→val 이동(10→13건)을 포함하지만 final 이동(→17건)보다 작다. 진짜 효과 확인은 LB뿐.
- 예상 시간: 30분
- GPU: 피처 계산에만 잠깐
