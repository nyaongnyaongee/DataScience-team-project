# 계획: 블렌드 결합 방식 (D041)
- 질문: B가 찾은 "minmax 점수 + RRF 혼합", "RRF c 작게"가 내 blend6에서도 오르나?
- 방법: blend.py에 --method mix (r·minmax + (1−r)·RRF/RRF최대) 추가. r ∈ {0,.25,.5,.75,.9,1}, c ∈ {10,20,30,60}.
  minmax는 모델마다 점수 척도가 달라 유저별 정규화 후 가중합.
- 베이스라인: blend6 0.05744 (rrf c=60)
- 성공 기준: > 0.05794. reranker 피처로 쓸지는 결과 보고 다음 실험에서 판단.
- CPU, 1시간.
